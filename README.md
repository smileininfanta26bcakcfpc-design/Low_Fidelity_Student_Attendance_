Project Overview
Student Attendance Management System is a simple and user-friendly UI/UX design created to manage student attendance efficiently. The design focuses on a clean interface with easy navigation between the Home Page, Login Page, and Dashboard.
The system provides students with quick access to their attendance information, daily activities, results, and profile.
Objective
To create a simple and attractive attendance management interface.
To make attendance information easy to access.
To provide clear navigation for students.
To design a consistent and user-friendly dashboard.
